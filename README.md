# Opengram

Клиент мессенджера Telegram, направленный на улучшение пользовательского опыта, повышение приватности и снятие части ограничений оригинала.

## Модификации оригинального кода Telegram

В отличие от многих других альтернативных клиентов, Opengram сознательно вносит минимум "правок" в код клиента, делает ноль своих сетевых запросов, а также соблюдает лицензию оригинала (привет "школьной" команде разработчиков exteraGram/AyuGram и им подобным). Список дополнительных улучшений:

1. Отключение рекламы в каналах/ботах/плеере;
2. Отключение большей части предложений купить Premium и их замена на информацию о соответствующих лимитах;
3. Снятие флага FLAG_SECURE с чатов/медиа с установленным запретом на пересылку и включение возможности сохранения (noForwards) в большинстве из них;
4. Унификация передаваемой информации об устройстве (часовой пояс, язык, модель, версия Android, performance_class, метод установки);
5. Подмена отпечатка клиента на более распространённый;
6. Принудительное включение ARM MTE на устройствах с его аппаратной поддержкой.

Подробнее о них можно прочитать по [этой](https://kremlinkernel.com/guide/hosting/1274/) ссылке.

## Уникальные функции Opengram
На данный момент, это:

1. Фильтр сообщений, Opengram Message Filter;
2. Режим призрака, который позволяет скрыть большинство действий от собеседников/серверов Telegram;
3. Возможность создавать (и использовать) только секретные чаты (т. е. сквозное шифрование) по умолчанию, Force End-to-End encryption;
4. Система безопасного резервного копирования сессий, Opengram Reload;
5. Возможность принудительно установить скорость загрузки для аккаунтов с Premium без самой подписки.

## Сборка
1. Клонируйте репозиторий:
```
git clone --recursive --shallow-submodules https://github.com/recultivationorg/opengram.git Opengram
```
2. Откройте директорию в Android Studio, дождитесь окончания синхронизации системы Gradle, затем
запустите сборку клиента через ```Build -> Generate signed app release or APK```. Вам нужен вариант ```aFatRelease```.
